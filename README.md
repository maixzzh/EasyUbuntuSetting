# Easy Ubuntu · 让Ubuntu的配置更简单

---

## 这是什么？

这是我对`Ubuntu`系统制作的可复用配置脚本，包括对于Hyprland和Waybar（均需要手动安装）的一键配置模板。对于懒人，这是一个非常不错的项目工具集

## 内容

```
.
└── waybar
    ├── config
    │   ├── config.jsonc
    │   ├── scripts
    │   │   └── diskio.sh
    │   └── style.css
    ├── hyprland
    │   ├── hyprland.conf.snippet
    │   └── hyprland.lua.snippet
    ├── install.sh
    └── README.md
```
